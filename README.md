# config-nvim

Мой личный конфиг Neovim.

## Установка

1. Скопируй содержимое репозитория в:
   - Windows: `%LOCALAPPDATA%\nvim`
   - Linux/macOS: `~/.config/nvim`
2. Запусти `nvim` — плагины установятся автоматически через `lazy.nvim`.

## Плагины

- lazy.nvim (менеджер плагинов)
- telescope.nvim (поиск файлов)
- everforest (тема)
- vim-fugitive (Git)
- nvim-autopairs (автозакрытие скобок)
